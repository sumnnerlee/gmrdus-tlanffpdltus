너는 시니어 프론트엔드 개발자야. 아래 명세대로 "단일 HTML 파일" 하나를 만들어줘. # 1. 프로그램 목적 대학 국제통상학과 학술제 발표용 "가정 기반 시나리오 비교 도구". 주제: 2023년 중국의 흑연 수출통제 사례를 가정으로, 한국의 흑연 조달 시나리오를 비교한다. 예측 프로그램이 아니라 시나리오 비교 도구임을 화면 하단에 작은 문구로 명시한다. ("본 도구는 가정값에 기반한 시나리오 비교용이며 실제 예측이 아닙니다.") 사용자는 통상 지식이 깊지 않은 청중이므로, 용어는 쉽게, 화면은 단순하게 만든다. # 2. 기술 조건 (필수) - 단일 HTML 파일(HTML+CSS+JS 한 파일). 외부 CDN/라이브러리/폰트 사용 금지(오프라인에서 동작해야 함). - 그래프는 순수 CSS 또는 SVG로 직접 그린다. - localStorage 등 브라우저 저장소는 사용하지 않는다. - 모든 가정값은 코드 맨 위의 CONFIG 객체 한 곳에 모아서, 나중에 숫자만 수정하면 되게 한다. - UI 언어는 한국어. 모바일 가독성은 신경 쓰되 기본은 노트북/프로젝터 화면 기준. # 3. 전체 구조 상단 탭으로 2개 창: - 「공급망 다변화」 창: 시나리오 A와 B를 "한 화면에 좌우로 나란히" 보여준다(페이지 이동 없음). - 「경로 차단」 창: 시나리오 A, B, C를 탭으로 전환하되, 화면 하단에 3개 시나리오를 한눈에 비교하는 표 + 막대그래프를 항상 보여준다. 각 창은 "인풋 영역 + 아웃풋 영역"이 같은 화면에 있어야 한다. 인풋을 바꾸면(슬라이더/숫자 입력) 버튼 없이 아웃풋이 즉시 갱신된다. # 4. 인풋 설계 ## 4-1. 공통 인풋 (맨 위에서 한 번만 입력, 두 창이 공유) - 연간 수입 수요량(톤): 기본 100 (※ 비율 비교용 가상 단위) ## 4-2. 공급처 정보 (표 형태, 행: 중국 / 대체국 X / 대체국 Y, 이름은 사용자가 수정 가능) 각 공급처별 입력 열: - 연간 최대 공급 가능량(톤) - 톤당 가격(USD) - 해상 운송시간(일) - 해상 톤당 운송비(USD) - 근거/출처 (자유 텍스트 입력칸, 기본값 "가정값 - 조사 후 수정") ## 4-3. 항공 정보 (중국발 항공 수입용) - 항공 운송시간(일), 항공 톤당 운송비(USD), 항공 월 최대 수송 가능량(톤) ## 4-4. 기본 가정값 예시 (CONFIG에 넣을 것, 임의 값임을 코드 주석에 표시) - 수요 100톤/년 - 중국: 최대 공급 150, 가격 1000, 해상 7일, 운송비 50 - 대체국 X: 최대 40, 가격 1150, 해상 25일, 운송비 120 - 대체국 Y: 최대 35, 가격 1200, 해상 30일, 운송비 140 - 항공: 3일, 톤당 운송비 3000, 월 최대 5톤 - 재고: 비축량 20톤, 단가 1000 - 경로 차단 기간 3개월 # 5. 시나리오별 로직 ## (1) 공급망 다변화 창 ※ 질문: "공급처를 다변화하면 수출통제 충격이 얼마나 줄어드나?" 추가 인풋: 중국 수출 감소율(슬라이더 0~100%, 기본 30%) — 중국의 실제 공급 가능량 = 최대공급량 × (1 − 감소율) - 시나리오 A (중국만 수입): 중국 비중 100%. - 시나리오 B (일부 대체): 중국/X/Y 비중 슬라이더(합계 100%가 되도록 자동 보정, 기본 60/20/20). 중국이 0%가 되지 않도록 중국 비중 최소값을 10%로 제한(전량 대체는 경로 차단 B와 구분하기 위함). 계산 (각 공급처별): - 목표 물량 = 수요 × 비중 - 실제 물량 = min(목표 물량, 해당 공급처의 실제 공급 가능량) - 공급 부족량 = 수요 − 실제 물량 합계(0 이상) ## (2) 경로 차단 창 ※ 질문: "중국발 경로가 갑자기 막혔을 때 어떤 대응이 나은가?" 추가 인풋: 차단 기간(개월, 슬라이더 1~12, 기본 3). 비교 기준 수요 = 수요 ÷ 12 × 차단 기간. 공급처 최대 공급량도 동일하게 ÷12 × 차단 기간으로 환산. - 시나리오 A (항공 수입): 중국에서 항공으로 수입. 실제 물량 = min(기준 수요, 항공 월 최대 수송량 × 차단 기간). 비용에는 항공 운송비를 적용. - 시나리오 B (다른 수출국 전량 대체): 중국 0%. X/Y 비중 슬라이더(합계 100%, 기본 50/50). 실제 물량 = min(목표, 공급 가능량). 부족분 계산. - 시나리오 C (재고 비축 활용): 인풋은 재고 비축량(톤), 재고 단가. 재고로 버틸 수 있는 기간(개월) = 비축량 ÷ (수요 ÷ 12). 차단 기간 동안 충당 물량 = min(기준 수요, 재고). 소요시간은 0일로 처리. 공급 부족량 = 기준 수요 − 충당 물량. # 6. 아웃풋 (모든 시나리오 공통 4개 + 보조 1개) 1. 총 조달비용 = Σ (톤당 가격 + 운송비) × 실제 물량 2. 평균 소요시간(일) = 물량 가중 평균 운송시간 3. 중국 의존도(%) = 중국산 신규 수입량 ÷ 전체 신규 수입량 (시나리오 C는 "해당 없음" 표시) 4. 공급 부족량(톤) 5. (시나리오 C 전용) 재고로 버틸 수 있는 기간(개월) # 7. 화면/UX 요구사항 - 아웃풋은 숫자 카드 + 막대그래프(SVG/CSS)로 표시. - 기준 시나리오(다변화 창은 A, 경로 차단 창은 B) 대비 증감률을 "+12%" / "-8%" 형태로 숫자 옆에 표시. 좋아지면 초록, 나빠지면 주황으로 표시. - 공급 부족량이 0보다 크면 해당 카드와 막대를 빨간색으로 강조하고 "⚠ 공급 부족 ○톤: 이 가정에서는 다변화만으로 수요를 채울 수 없음" 경고 문구를 크게 표시. - 모든 숫자 인풋은 슬라이더 + 숫자 입력칸을 함께 제공하고 서로 동기화. - "초기값으로 되돌리기" 버튼 제공(CONFIG 기본값으로 복원). - 각 창 하단에 접었다 펼 수 있는 "계산식 보기" 패널을 두고 위 계산 로직을 한국어 수식으로 보여준다. - 공급처 표의 "근거/출처" 칸은 항상 보이게 한다. - 디자인: 깔끔한 흰 배경, 시나리오별 고정 색상(A 파랑, B 초록, C 보라), 큰 글씨(발표용 가독성). # 8. 작업 방식 - 먼저 CONFIG 구조와 계산 함수(순수 함수)를 작성하고, 그다음 UI를 연결해라. - 계산 함수는 입력값 → 결과 객체를 반환하는 형태로 분리해서 나중에 테스트/수정이 쉽게 해라. - 코드 맨 위에 주석으로 "가정값 수정 위치"를 안내해라. - 완성 후, 직접 실행해서 기본값에서 (1)-A/B, (2)-A/B/C 결과 숫자가 계산식과 일치하는지 한 번 검증해라.
